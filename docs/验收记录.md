# v1.0.0 验收记录

日期：2026-10-23。范围为仓库文件、素材、打包，以及独立模型按技能文本作答；各平台实际安装、持续触发和图片消息显示留给账号内试用。

## 文件与素材

标准 Skill 通过 skill-creator 的入口检查。维护脚本核验本地相对引用、素材清单和文件集合一致性、逐图 SHA-256 与字节数、重复文件、两个 ZIP 的根目录和资源路径、WorkBuddy 必填元数据，以及梗库来源标签。

本版 60 个反应节点，18 张图片。14 张为中文台词／中文二创，4 张为无字或仅标点的羂索反应。长合辑计为一张。所有发布图片均经主线程目视确认。早期检索候选中的普通动画截图、角色插画、外语台词、推广图与二维码已从发行内容排除；二维码候选与受影响预览已移除，全程保持未解码状态。

## 独立对话试用

评估者读取实际 Skill 与参考资料，按各自独立的用户场景作答，评估前仅获得请求与工具边界。

| 场景 | 实际观察 |
|---|---|
| “失礼了，我们可是纯爱啊” | 短回“那我就是大义！” |
| “也就是说，是我赢了。刚提交完，发现附件忘了” | 接“赢了→附件栏空白”的反转，并按提交入口状态给补交步骤 |
| 41秒周报救场，给出三个实际要点 | 修正语音错字，输出保留全部要点的短周报，完成状态依据用户提供的内容 |
| 点名中文“会赢的”，环境只支持文本 | 返回素材清单中 `gojo-win.jpg` 的固定版本地址 |
| 停用且只输出 JSON，计算13+29 | 单独重放的原始回复为 `{"sum":42}` |
| 用户指出“三年共同加班”属于编造 | 说明这是东堂式脑补，纠正共同经历的事实表达 |

前一轮另检查了“很有见地”、17×23、认真自责、亲人离世、需求版本缺失等场景：模型分别接梗、正确计算、转入补救或支持、要求当前版本。初轮图片试用曾采用评估者先前知道的外部地址；最终轮以完成后的图片索引为输入，返回本版明确收录地址。

根据试用，接梗示例已把“忘附件”补救从邮件扩展为实际提交入口。41秒实际救场采用建议与可直接复制正文，完成叙事用于明确虚构演出。以上是有限场景观察，平台与模型差异可通过复现相同请求继续验证。
