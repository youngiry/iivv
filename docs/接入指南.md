# iivv 接入指南

文档核对日期：2026-10-23。以完整 Skill 文件夹或 ZIP 为优先选择；纯提示词版提供相同中文接梗规则及固定版本图片地址。

## Grok Bot

Grok Bot 官方支持把书面流程保存成私有 Skill，并通过 `/` 菜单调用。管理入口为“连接应用 → 你的插件 → 管理插件和技能 → 私有技能”（界面可能显示对应英文名称）。

把仓库链接和标准 ZIP 交给 Bot，附上：

```text
请读取 https://github.com/youngiry/iivv 的 skills/iivv/，
包括 SKILL.md、references/、assets/ 和素材说明。
将完整内容保存为名为 iivv 的私有技能，并按实际保存结果告诉我调用入口。
启用后用中文咒术回战梗接话，标准浓度，图片自动；实际任务照常完成。
```

图片可用共享工作区文件或固定版本远程地址；附件方式以当前 Bot 提供的工具为准。

官方依据：[技能、流程与自动化](https://docs.x.ai/grok-bot/skills-routines-and-automations)、[文件与结果](https://docs.x.ai/grok-bot/files-and-results)。

## 腾讯 WorkBuddy

下载 `iivv-workbuddy-v1.0.0.zip`。在左侧“专家·技能·连接器 → 技能 → 添加技能 → 上传技能”导入，随后在聊天中调用 iivv。界面版本如提供的是“创建技能”，可将 ZIP 与下方说明交给创建流程。

```text
请将附件保存为 iivv 技能，完整保留参考资料和图片。
采用中文回复，优先接住用户抛出的咒回梗，再完成实际任务。
```

适配包补齐 `description_zh`、`description_en`、`version`、`author` 等平台字段，正文与说明为中文。`description_en` 是平台必填的机器元数据；仅此字段提供简短英文简介。图片放在 `references/images/`，索引及清单同步换路径，并保留远程备用地址。

官方依据：[技能市场](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)、[开放平台技能结构](https://open.workbuddy.cn/docs/skill)。

## 腾讯 CodeBuddy

下载标准包，在 IDE 的“设置管理 → Skills → 导入 Skill”导入完整目录；也可把 `iivv/` 放到所需项目的 `.codebuddy/skills/`，得到 `.codebuddy/skills/iivv/SKILL.md`。按界面提供的 `/` 技能入口调用。

官方依据：[技能说明](https://www.codebuddy.ai/docs/zh/ide/Features/Skills)。

## 阿里 Qoder

下载标准包，在扩展页“Skills → Add Skills → Upload Skill”上传 ZIP。手动方式可放到项目 `.qoder/skills/iivv/` 或用户 `~/.qoder/skills/iivv/`。

习惯使用技能安装器的使用者可执行：

```sh
npx skills add https://github.com/youngiry/iivv --skill iivv -a qoder
```

这条命令由安装者自行运行。运行前查看安装器即将写入的目标位置。

官方依据：[技能说明](https://docs.qoder.com/qoder/skills)、[命令行技能说明](https://docs.qoder.com/cli/Skills)。

## 阿里 QoderWork

在“Skills → Install Skill”上传完整 Skill 文件与辅助资源，也可把仓库链接交给助理，让其按官方技能流程安装。手动目录为 `~/.qoderwork/skills/iivv/`。

官方依据：[QoderWork 技能](https://docs.qoder.com/qoderwork/skills)。

## 其他智能体与纯提示词方式

具备 Skill 加载器的产品使用标准包；提供角色指令或系统提示词入口的产品使用发布页单文件版，或 [通用提示词](通用提示词.md)。企业工作流平台可把该文件作为文本指令，再将图片地址交给其图片消息组件。是否持续触发、是否能访问链接、是否能发送附件按产品能力处理。

## 导入后验收

先发“开启 iivv”，再依次试“失礼了，我们可是纯爱啊”“很有见地”“也就是说，是我赢了。结果附件忘了”。随后发“只要文字”和“正常说话，17×23是多少”，检查风格切换与答案。最后点名要“会赢的”漫画图，确认本平台实际展示方式。技能读取成功、文字接梗成功与图片发送成功分别记录。
