一刻也没有为上一句正常回复哀悼，立刻赶赴聊天框的是——**iivv**。

给你的 AI 接入一点 jjxx 风味。你聊纯爱，它谈大义；你刚宣布胜利，它已经翻到下一话；你临时加需求，它头上的轮子转了一下。

活照干，梗照接。交稿前的最后41秒，咒术师也得核对附件。

## 也就是说，是你的 AI 赢了

> 你：单测全绿，上线就炸。<br>
> iivv：也就是说，是我们赢了。——生产环境翻开了下一话。

> 你：我准备最后一天再开始写。<br>
> iivv：很有见地。但是——那是废物的思维。真正的强者今天就建好文档，提前和空白页对峙六天。

> 你：只是简单改一下，今晚把这三百张表处理了。<br>
> iivv：我？今晚？打三百张宿傩？

> 你：最终版、最终版2、最终版真的最终，这几个到底哪个才是？<br>
> iivv：全都是因为我。是我对“再改一下”的执念，让最终版学会了繁殖。所以，领域展开——文件名里写日期。

> 你：还有一分钟交周报，来段41秒。<br>
> iivv：在提交发动前的41秒内，工位再次响起了我的吟唱：“本周完成”“当前卡点”“下周计划”。最强的周报，铭刻于提交记录。

> 你：需求又改了，你适应一下。<br>
> iivv：轮子转了。再改两版，我就能在你开口之前说“收到”。

以上是聊天演示。真到干活时，问题照答、文件照改、步骤照给。嘴上可以提前开香槟，完成状态按实际结果报。

## 很有见地，看看你的术式

**60 个接梗节点。** 鹿紫云负责紫曰，五条负责赛前采访，日下部负责临时接锅，乙骨负责自责之后开领域，东堂负责当场认亲。羂索准备了一千年，最后负责表情管理。

**18 张现成网络图。** 14 张中文漫画或恶搞图，4 张无字／仅标点的脑花反应图。长合辑按一张计数，原图和水印保留。你负责把话说抽象，脑花负责露出这个表情：

## 立刻赶赴聊天框的是——你的助理

先从 [发布页](https://github.com/youngiry/iivv/releases/latest) 领取术式：

| 领取入口 | 谁来上场 |
|---|---|
| [标准 Skill ZIP](https://github.com/youngiry/iivv/releases/download/v1.0.0/iivv-v1.0.0.zip) | 支持完整 Skill 的助理；梗库、图片一起带上 |
| [WorkBuddy 适配 ZIP](https://github.com/youngiry/iivv/releases/download/v1.0.0/iivv-workbuddy-v1.0.0.zip) | WorkBuddy 专用，平台字段和资源路径已调整 |
| [单文件提示词](https://github.com/youngiry/iivv/releases/download/v1.0.0/iivv-prompt-v1.0.0.md) | 角色指令、自定义助理；复制进去，准备受肉 |

**Grok Bot** 可读取仓库或 ZIP 后保存为私有 Skill；**WorkBuddy** 使用适配包；**CodeBuddy、Qoder、QoderWork** 使用标准包。导入完整技能目录，再说一句：

```text
开启 iivv，标准发癫，表情包自动。
```

具体点哪里、怎么导入，见 [接入指南](docs/接入指南.md)。其他智能体按自己的 Skill 或角色指令入口接入；图片随平台能力展示，纯文字也能开领域。

## 和它立下束缚

```text
淡一点。                     # 留点咒力给正事
再疯一点。                   # 领域对拼开始
只要文字。                   # 脑花暂时收起鬼脸
少剧透。                     # 香槟先存着
这次用乙骨自责的口吻。       # 全都是因为我
来一段提交前41秒的解说。     # 工位响起吟唱
正常说话。                   # 当轮恢复普通回复
```

默认标准浓度、图片自动。轻度偶尔点一句，重度可以连着接几个包袱。认真求助、悲伤倾诉、正式文稿和严格输出格式，按你的事情本身处理。连续生效由平台的技能调用与会话偏好决定。
