# iivv

**让你的 AI 听得懂咒回梗，也接得住下一句。**

> 你：失礼了，我们可是纯爱啊。  
> iivv：那我就是大义！

> 你：也就是说，是我赢了。刚提交就发现附件忘了。  
> iivv：没错，是你赢了。——系统下一话：附件栏，空白。趁现在补发附件，写清它对应刚才那封邮件。

> 你：要不留到最后一天，再靠肾上腺素写完？  
> iivv：很有见地。但是——那是废物的思维。真正的强者今天就建文档，然后和空白页展开领域对拼。

这是一份中文咒术回战搞怪 Skill：漫画台词、紫曰、嘴硬反转、鬼脸与夸张解说。它先理解上下文，再选梗、接梗、改梗；遇到实际任务，答案和办事能力照常保留。

## 里面有什么

- **60 个反应节点**：五条、鹿紫云、乙骨、夏油、羂索、高羽、宿傩、日下部、魔虚罗、秤金次、东堂和虎杖。成对答句分别计为节点，标点变体合并。
- **18 张现成网络图**：14 张中文漫画或恶搞图，3 张无字脑花反应图，1 张只有感叹号的鬼脸。长合辑按一张计数。每张带来源与哈希，保留原图、水印和繁简体。
- **会接半句**：“纯爱→大义”“很有见地→但是”“也就是说→是 XX 赢了”。看得懂“茨／茈”“废物／杂鱼”等常见写法。
- **会按场景续写**：乙骨自责、41秒解说、接力登场、适应之轮、坐杀博徒、脑中出现的记忆。
- **浓度可调**：轻度、标准、重度；只文字、配图、少剧透、单次使用、连续模式。

支持标准 `SKILL.md` 的平台直接导入完整技能目录。只上传入口文件时，宿主还需要读取配套参考资料；ZIP 最方便。

**Grok Bot** 可读取仓库或 ZIP 后保存成私有 Skill；**WorkBuddy** 使用适配包；**CodeBuddy、Qoder、QoderWork** 使用标准包。具体入口和可复制提示词见 [接入指南](docs/接入指南.md)。更多腾讯、阿里或其他厂商的智能体，可按“完整 Skill／角色指令／纯文字”三种能力选择接入方式。

本版验证范围：文件结构、图片和链接引用、ZIP 内容、独立模型场景试用。各平台路径依据官方文档整理；平台实机安装与附件显示由使用者在自己的账号中验收。图片发送依赖宿主提供的真实能力，纯文字环境照常接梗。

## 怎么玩

```text
开启 iivv，标准发癫，表情包自动。
再疯一点。
只要文字。
少剧透。
这次用乙骨自责的口吻。
来一段提交前41秒的解说。
正常说话。
```

“会赢的”负责气势，真实结果照证据说。认真求助、悲伤倾诉和严格输出格式会按当前任务处理；平时聊天可以放心抛梗。安装提供调用入口，是否在后续对话持续开启由宿主的技能调用与偏好机制决定。

## 开发与补梗

运行环境：Python 3.10 及以上，打包与结构检查使用标准库。

```sh
python scripts/build.py
python scripts/verify.py
```

新增梗时，在梗库里写清“短线索、适合什么场景、怎么接、来源”；新增图片时同步更新素材清单和图片索引。欢迎通过议题或拉取请求补中文漫画恶搞图、反转台词和有趣的接法。贡献规则见 [补梗说明](CONTRIBUTING.md)。
